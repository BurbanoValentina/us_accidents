Consulta SQL (Optimizada con Índices SQLite / DuckDB / PySpark) 
-- Requerimiento 1: Frecuencia de accidentes por Estado y Ciudad
SELECT 
    state,
    city,
    COUNT(*) AS total_accidentes,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM us_accidents_limpio), 2) AS porcentaje_nacional,
    ROUND(AVG(severity), 2) AS severidad_promedio
FROM us_accidents_limpio
WHERE state IS NOT NULL AND city IS NOT NULL
GROUP BY state, city
ORDER BY total_accidentes DESC
LIMIT 15;

Análisis por Severidad del Accidente

SELECT 
    severity,
    COUNT(*) AS total_accidentes,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM us_accidents_limpio), 2) AS porcentaje,

Consulta SQL (Optimizada con Índices SQLite / DuckDB / PySpark) 
-- Requerimiento 5: Tipos de vía clasificados por regex
SELECT 
    CASE 
        WHEN street LIKE '%I-%' OR street LIKE '%Interstate%' OR street LIKE '%Fwy%' OR street LIKE '%Hwy%' THEN 'Interestatal / Autopista'
        WHEN street LIKE '%St%' OR street LIKE '%Street%' THEN 'Calle Urbana'
        WHEN street LIKE '%Ave%' OR street LIKE '%Blvd%' THEN 'Avenida / Bulevar'
        WHEN street LIKE '%Rd%' OR street LIKE '%Road%' THEN 'Carretera Local'
        ELSE 'Otra Vía'
    END AS tipo_de_via,
    COUNT(*) AS total_accidentes,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM us_accidents_limpio), 2) AS porcentaje,
    ROUND(AVG(severity), 2) AS severidad_promedio
FROM us_accidents_limpio
GROUP BY tipo_de_via
ORDER BY total_accidentes DESC;

-- Requerimiento 6: Distribución por día de la semana
SELECT 
    CASE CAST(strftime('%w', start_time) AS INTEGER)
        WHEN 0 THEN 'Domingo'
        WHEN 1 THEN 'Lunes'

Promedio de Duración del Incidente

duration_raw vs duration_clean_min

Pregunta de negocio: ¿Cuál es la duración real de un incidente y cuál fue el impacto del filtrado de valores atípicos y sensores trabados?

Media Bruta Original 444.40 min Sesgada por outliers
Media Depurada Limpia 108.03 min Vía despejada en 1.8h
Mediana Operativa 74.75 min Métrica más robusta
Atípicos Eliminados (>24h) 34,981 filas Sensores trabados

Respuesta & Hallazgo Clave

La media bruta original calculada directamente en bruto arrojaba un valor distorsionado de 444.40 minutos (más de 7.4 horas) debido a 34,981 registros donde el sensor no cerró la alerta a tiempo. La aplicación del filtro de calidad de datos en PySpark eliminó las duraciones >24h, obteniendo una duración promedio limpia y verificada de 108.03 minutos con una mediana representativa de 74.75 minutos.

Gráfica Analítica (Python Matplotlib/Seaborn) Ampliar
Evidencia en Terminal SQL Ver terminal
Consulta SQL (Optimizada con Índices SQLite / DuckDB / PySpark) 
-- Requerimiento 7: Comparativa de duración bruta vs limpia
SELECT 
    severity,
    ROUND(AVG(duration_clean_min), 2) AS duracion_media_limpia_min,
    MIN(duration_clean_min) AS duracion_minima_min,
    MAX(duration_clean_min) AS duracion_maxima_min,
    COUNT(*) AS total_accidentes
FROM us_accidents_limpio
WHERE duration_clean_min IS NOT NULL
GROUP BY severity
ORDER BY severity ASC;

Gráfica Analítica (Python Matplotlib/Seaborn) Ampliar
Evidencia en Terminal SQL Ver terminal
Consulta SQL (Optimizada con Índices SQLite / DuckDB / PySpark) 
-- Requerimiento 9: Extracción NLP por tipo de vehículo en description
SELECT 
    CASE 
        WHEN LOWER(description) LIKE '%truck%' OR LOWER(description) LIKE '%semi%' OR LOWER(description) LIKE '%trailer%' THEN 'Camión / Tráiler'
        WHEN LOWER(description) LIKE '%car%' OR LOWER(description) LIKE '%sedan%' OR LOWER(description) LIKE '%suv%' THEN 'Automóvil / SUV'
        WHEN LOWER(description) LIKE '%motorcycle%' OR LOWER(description) LIKE '%bike%' THEN 'Motocicleta'
        WHEN LOWER(description) LIKE '%bus%' THEN 'Autobús'
        WHEN LOWER(description) LIKE '%pedestrian%' THEN 'Peatón'
        ELSE 'No especificado en texto'
    END AS categoria_vehiculo,
    COUNT(*) AS total_accidentes,
    ROUND(AVG(severity), 2) AS severidad_promedio
FROM us_accidents_limpio
GROUP BY categoria_vehiculo
ORDER BY total_accidentes DESC;

-- Requerimiento 10: Puntos críticos viales con infraestructura asociada
SELECT 
    state,
    city,
    street,
    COUNT(*) AS total_accidentes,

Inferencia Estadística & Validación Paramétrica α = 0.05

Análisis de Varianza (ANOVA One-Way) por Severidad

Evaluación matemática de diferencias estadísticamente significativas entre los 4 niveles de severidad (1, 2, 3 y 4) para las variables continuas duration_clean_min (duración del incidente en minutos) y visibility_mi (visibilidad atmosférica en millas).

H₁

Variable: Duración Limpia (duration_clean_min)

Hipótesis Nula (H₀):

μ₁ = μ₂ = μ₃ = μ₄. No existen diferencias en la duración media de los accidentes viales entre los 4 niveles de severidad.

Hipótesis Alternativa (Hₐ):

Al menos una media μᵢ es diferente. La severidad del accidente influye significativamente en la duración del impacto vial.

H₂

Variable: Visibilidad (visibility_mi)

Hipótesis Nula (H₀):

μ₁ = μ₂ = μ₃ = μ₄. La visibilidad atmosférica promedio es idéntica en todos los niveles de severidad vial.

Hipótesis Alternativa (Hₐ):

Al menos un nivel de severidad presenta una visibilidad significativamente menor o diferente a los demás grupos.

Conclusiones del Análisis Inferencial

Interpretación Paramétrica

Ambas pruebas ANOVA F arrojaron p-valores sustancialmente inferiores al umbral crítico α = 0.05. En consecuencia, se rechaza categóricamente la hipótesis nula en ambos casos: la severidad del accidente influye tanto en la duración de la afectación como en la visibilidad promedio.

Implicación Operativa

Aunque estadísticamente significativo debido al tamaño muestral masivo, el tamaño del efecto (Eta cuadrado η² < 0.5%) evidencia que la duración también está condicionada por la hora del día, el tipo de carretera y la capacidad de respuesta de los cuerpos de auxilio vial.
